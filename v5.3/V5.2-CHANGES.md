# Kardna V5.2 changes

## Branding

- Removed all visible and internal Kardna OS naming.
- The site, metadata, server output, navigation, footer, settings, proxy page, and documentation now use Kardna.

## Visual redesign

- Monochrome black-and-white interface.
- Large glowing Kardna hero lettering and a lightweight gradient-grid background.
- Focused liquid glass on navigation, search, command palette, player controls, settings, and proxy controls.
- Liquid glass can be disabled in Settings and is automatically removed by low-performance mode.
- Game cards are grayscale at rest and reveal their actual artwork colors on hover.
- Each hovered card reuses its own artwork as the ambient color glow.
- Pointer lighting and tilt are updated with one requestAnimationFrame only while the card is actively hovered.
- Touch, reduced-motion, and low-performance modes use a simpler static card treatment.

## Game import

The supplied legacy game catalog was normalized and merged into the existing catalog.

- Existing catalog: 58 records
- Legacy source: 129 records
- Placeholder `example.com` records skipped: 16
- Duplicate/local-folder records skipped: 42 total skipped entries
- Final catalog: 144 unique records

The runtime now accepts either a modern array or an older `{ "games": [...] }` object and recognizes both `name`/`url` and `title`/`iframe` fields.

External game URLs are prepared through the selected Kardna proxy engine at launch time. If the local proxy runtime is unavailable, Kardna attempts the original iframe URL and displays a notice.
