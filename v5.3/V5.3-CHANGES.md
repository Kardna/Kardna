# Kardna V5.3 changes

## Interface

- Removed the visible “Skip to content” link from the document shell.
- Kept the black-and-white Kardna design and liquid-glass navigation, search, player, settings, and proxy surfaces.
- Game artwork now remains monochrome at rest and on hover. Hovering only changes contrast, brightness, scale, and white lighting.
- The image-derived ambient effect is also forced to grayscale, so no colored glow leaks into the interface.

## Game artwork

- Reused matching online artwork and live-page captures from the supplied legacy catalog where the title matched.
- Added matching online captures for several local catalog games that previously used generated cards.
- Removed generic Google Images search-result screenshots.
- 106 of 144 catalog entries now use title-matched online artwork; the remaining 38 use local artwork for Kardna-original or obscure bundled games.

## Local game paths

- Every local game URL now uses the explicit relative format `./games/<folder>/...`.
- `npm run sync-games` now recognizes and writes `./games` paths.
- The path helper resolves both `/games/...` and `./games/...` correctly under localhost and subfolder deployments.

## Player controls

- Moved the disappearing player dock to the top of the game frame so it cannot sit below the visible game area.
- Moved the controls panel beneath the top dock.
- Preserved fullscreen, theater, restart, mute/unmute, favorite, report, exit, and next-game functionality.
